# Ionic or Covalent? — Names & Formulas

A SCORM 1.2 activity for Schoology. It follows the ionic-naming activity and adds covalent
(molecular) compounds. The emphasis is the **decision** of which naming rules to use:

```
Does it start with a metal (or NH₄⁺)?
  YES → IONIC. Is the metal a transition metal?
          YES → metal (Roman numeral) + negative ion        iron(III) oxide
          NO  → metal + negative ion                        calcium chloride
  NO, two nonmetals → COVALENT → prefixes, never a Roman numeral
          mono- is dropped on the first element             dinitrogen tetroxide, carbon monoxide
```

**Nothing is typed.** Every answer is built from tiles.

Same constraints as the ionic activity:

- only elements 1–20, Honors Element List 2 and the class Polyatomic Ions List;
- Sn and Pb count as transition metals, Ag and Zn do not;
- mercury is used as Hg²⁺ only;
- completion-only grading.

---

## The three levels

| Level | Name | What the student does |
| --- | --- | --- |
| 1 | Which rules? | 16 formulas. For each, pick **Ionic — no Roman numeral**, **Ionic — Roman numeral**, or **Covalent — prefixes**. Both elements are highlighted on the periodic table, and the answer screen shows the compound's name. |
| 2 | Mixed practice | 14 questions: 7 names and 7 formulas; 5 covalent, 4 ionic and 5 transition-metal ionic. Every question starts with *Which naming rules apply?*, then the steps for that branch. The decision flowchart beside the question lights up the branch being used. |
| 3 | On your own | 14 more of the same mix, with no steps and no flowchart. Just the builder. |

Level 2 branch steps:

| Branch | Naming a formula | Writing a formula from a name |
| --- | --- | --- |
| Ionic | how many polyatomic ions (when there are parentheses) → build | charge of each ion → build |
| Ionic + TM | total negative charge → charge on each metal → build | charge of each ion → build |
| Covalent | build straight from the atoms | build straight from the prefixes |

### How every level is mixed

- **The three rule sets are interleaved.** The same rule set never comes up three times in a
  row. In Levels 2–3, names and formulas alternate the same way.
- **Look-alike pairs sit side by side.** Level 1 has four pairs per run and Levels 2–3 have
  one, for example:
  - SnCl₄ / CCl₄
  - PbO₂ / SiO₂
  - Fe₂O₃ / N₂O₃
  - CoO / CO
  - NH₄Cl / NCl₃
  - NaNO₂ / NO₂
  - Na₂SO₃ / SO₃
  - KF / KrF₂
  - AgCl / CuCl
  - MgF₂ / MnF₂

  The full list is in `ANSWER_KEY.md`.
- **Required cases in every run.**
  - Level 1: an Ag or Zn compound, an Sn or Pb compound, ammonium, and a noble-gas compound.
  - Levels 2–3 add: a covalent formula students are tempted to reduce (N₂O₄, P₄O₁₀), a
    *mono-* on the second element, a first-element prefix, a TiO₂/PbO₂ reduction, an ionic
    formula with parentheses, and a Cu⁺ or Au⁺ compound.

### The builders

The **name builder** has the same five rows for every compound:

```
[prefix]  [first part]  [Roman numeral]  [prefix]  [second part]
```

Students choose "none" in whichever rows their rule set doesn't use. Picking the right rows is
part of every answer. The builder spells the vowel drop itself (*monoxide*, *tetroxide*,
*pentoxide*).

The **formula builder** has two parts, a count of 1–10 for each, and a **( )** switch for each.

### Feedback on the cross-over mistakes

| Mistake | Feedback |
| --- | --- |
| *calcium dichloride* | This is ionic — Ca is a metal — so no prefixes. The charges already fix how many of each ion there are. |
| *iron trichloride* | Ionic names never use prefixes. Iron is a transition metal, so show its charge with a Roman numeral instead. |
| *carbon(IV) oxide* | This is covalent: there are no ions and no charge to show. Count the atoms and use prefixes. |
| *monocarbon monoxide* | Drop mono- on the first element. |
| *carbon oxide* | The second element always gets a prefix — even mono-. |
| *nitrogen dioxide* for N₂O₄ | Count the atoms exactly — never reduce a covalent formula. Nitrogen dioxide is NO₂, a different compound. |
| NO₂ for dinitrogen tetroxide | Never reduce a covalent formula. NO₂ is a different compound: nitrogen dioxide. |
| CaCl for calcium chloride | This is ionic, so "no prefix" does NOT mean one of each. The charges decide. |
| NO₂ for sodium nitrite | NO₂ on its own is nitrogen dioxide, a covalent molecule. Sodium nitrite needs its Na⁺ too. |
| CoO for carbon monoxide | Co is cobalt. Carbon is C. |

All the ionic feedback from the previous activity is still there: Roman numeral vs subscript,
reduced formulas, parentheses, peroxide, and the Ag/Zn/Sn/Pb rule. After 3 wrong tries on a
build, the answer is shown.

### Check for understanding

- A check question comes after every 2nd question in Level 2, every 3rd in Level 3 and every
  4th in Level 1, plus a **3-question checkpoint** at the end of each level. That's about 22 per
  run.
- The bank has 114 written questions:
  - 36 new ones on the decision, prefixes, never reducing a covalent formula, and cross-over
    mistakes;
  - the 78 from the ionic activity.
- Generated questions cover:
  - "Which naming rules apply to …?";
  - covalent name ↔ formula;
  - ionic name ↔ formula;
  - the charge on a metal.
- A missed check brings back a different question on the same idea later in the level.

## Compounds

- **Ionic:** the same 933-compound pool as the ionic activity, polyatomic ions included.
- **Covalent:** 63 real compounds of nonmetals on the memorized list. Examples:
  - CO, CO₂, CS₂ and CCl₄
  - N₂O to N₂O₅, plus NF₃ and NI₃
  - PCl₃/PCl₅, P₂O₅, P₄O₆, P₄O₁₀ and P₄S₃
  - SO₂/SO₃, SF₄/SF₆ and S₂Cl₂
  - SiO₂, SiCl₄, BF₃ and B₂O₃
  - ClF₃, BrF₅, IF₇, ICl, Cl₂O₇, I₂O₅ and OF₂
  - XeF₂, XeF₄, XeF₆, XeO₃ and KrF₂
- **Left out:**
  - **Hydrogen compounds** (H₂O, NH₃, CH₄, HCl, H₂S), which use common names or are acids.
  - **SiC**, whose usual name breaks the mono- rule.
- **Noble gases:** Kr and Xe compounds are included because they are on the memorized list.
  The feedback explains that noble gases never form ions but the heavy ones share electrons.

`ANSWER_KEY.md` lists every compound, the look-alike pairs, and the written question bank.

## The periodic table

The table is AP-style: atomic number, symbol and mass, with no names and no charges. It adds
one thing the College Board table doesn't have: **the thick metal/nonmetal staircase**. It runs
along B, Si, Ge, Sb, Te and At. Everything to its left is a metal; B and Si are metalloids that
behave as nonmetals here. A key under the table says so.

In Level 1 the table sits beside the question with both elements highlighted. In the other
levels it's one button away. The footer links to the official College Board PDF.

## Grading and saving

**Completion only.** The status becomes `completed` when Level 3 is finished, and no score is
written. Progress saves after every answer and resumes where the student left off. The saved
data is under 1,200 characters, against SCORM 1.2's 4,096-character limit.

Bump `SCHEMA` in `src/js/game.js` whenever you change the levels, the draw or the compound
lists.

## Building and uploading

```bash
./build.sh                    # → dist/ionic-covalent-v1.zip
```

Upload `dist/ionic-covalent-v1.zip` in Schoology with **Add Materials → Add File** (or
**Package**). Then open it once with **Preview as Student**: the top-right badge should read
**Connected to the LMS**. If it sits on "Importing SCORM Package…", refresh after a minute.

A built zip is committed. Add `?level=N` (1–3) to `src/index.html` for a teacher preview that
saves nothing.

## Editing

| To change | Edit |
| --- | --- |
| Covalent compounds, prefixes, look-alike symbols | `src/js/data.js` (`COVALENT`, `PREFIXES`, `COV_NEAR`) |
| Transition metals, charges, ions | `src/js/data.js` |
| Check questions | `src/js/cfu.js` |
| Items per level, rule-set targets, pairs, required cases | `src/js/plan.js` (`LEVELS`, `PAIRS`, `REQUIRED`) |

After any edit:

```bash
node tools/validate.js
node tools/answer-key.js > ANSWER_KEY.md
./build.sh
```

`tools/validate.js` checks that:

- every compound uses memorized elements only;
- every covalent compound is two different nonmetals, with no hydrogen, and its name follows
  the prefix rules;
- every formula and every name is unique across ionic and covalent;
- the correct tiles are accepted for all 996 compounds, and every cross-over mistake is
  rejected;
- 2,000 simulated runs each:
  - hit the rule-set targets and the required cases;
  - place the look-alike pairs side by side;
  - never repeat a rule set three times in a row, or three names or three formulas;
  - fit the SCORM save limit.

No CDN, no web fonts and no network calls. Everything is a real button or checkbox, so it
works with a keyboard, and feedback is announced to screen readers. It follows the device's
dark mode and works on phones.

# Volleyball

## Volleyball Rankings app

The rankings program (Elo / Massey / Colley / FPI ratings, SportWrench scrapers,
live scorer, win probability) lives in its own **private** repository because it
is deployed to Render from there:

https://github.com/coachcherry1/Volleyball-Rankings

On any computer: `git clone https://github.com/coachcherry1/Volleyball-Rankings`
(sign in to GitHub as `coachcherry1`; it is private, so it will not show up
when logged out). Its live copy runs from the Render/Neon setup described in
that repo's `DEPLOY.md`.

Put any future volleyball projects in this folder.

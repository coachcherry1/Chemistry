    How to use
    • Fastest: type a formula and press Draw — SO4 2-, H2SO4, NH4+, CO2, NaCl, NO2. Single-central-atom species follow the 5 rules; molecules like ethanol and acetic acid are in Common molecules.
    • Atom: tap the grid to place an atom. Tap an atom to select it — every atom you place next is bonded to it. Bond: tap two atoms; tap a bond to make it double, then triple. Lone pair: tap an atom. Fill electrons completes every octet at once.
    • Drag an atom to move it; hold Shift while dragging to move the whole molecule.
    • Resonance: select an atom and press Duplicate →: a copy appears with ↔ between. Move a double bond in the copy. A Partial bond (solid + dashed) draws a hybrid.
    • Getting the picture out: Snip view shows only the structure, big — then use your snipping tool (Windows: Win+Shift+S; Chromebook: Ctrl+Shift+Show windows; Mac: Cmd+Shift+4). Copy image and PNG/SVG work too when the page allows it (some LMS frames block them).
    • Keys: Ctrl+Z / Ctrl+Y undo and redo; Delete removes what is selected; 1, 2, 3 set a selected bond; Esc clears the selection; with the drawing focused, arrow keys nudge (Shift: the whole molecule).

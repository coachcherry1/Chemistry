# Unit 0 – Honors Review — Simulation Index

**Course:** AP Chemistry
**Schoology unit:** Unit 0 – Honors Review
**Last updated:** 2026-09-07

Each simulation folder holds `<name>/index.html` + `imsmanifest.xml`, with a ready-to-upload
`<name>-scorm.zip` beside it. SCORM 1.2, completion-graded, no student-name gate.

## Simulations

### `empirical-molecular-formula-lab` — Empirical & Molecular Formula Lab Challenge
From percent-composition or combustion-analysis data, work out the empirical formula, then
use a given molar mass to find the molecular formula.

### `ideal-gas-law-practice` — Ideal Gas Law Practice
PV = nRT problems — solve for any variable, with unit conversion (atm/kPa/mmHg, °C→K, L).

### `stoichiometry-conversion-practice` — Stoichiometry Conversion Practice
Mass–mass, mole–mole, and mass–mole stoichiometry from a balanced equation. Completion-only,
unlimited retries, no skip.

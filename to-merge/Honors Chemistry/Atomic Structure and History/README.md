# Atomic Structure and History — Simulation Index

**Course:** Honors Chemistry
**Schoology unit:** Atomic Structure and History
**Last updated:** 2026-09-07

Each simulation folder holds `<name>/index.html` (or `<name>.html`) + `imsmanifest.xml`,
with a ready-to-upload `<name>-scorm.zip` beside it. All are SCORM 1.2, completion-graded,
no student-name gate.

## Simulations

### `isotope-atomic-mass` — Isotope Atomic Mass Practice
Given isotope masses and percent abundances, calculate the weighted average atomic mass
(and work the reverse direction).

### `isotope-tables` — Interactive Isotope Table Simulator
Fill in a 3-row isotope table — protons, neutrons, electrons, mass number, nuclear
symbol, charge — all blanks graded together.
**Completion:** 5 full tables correct (unlimited retries; auto-advances after a correct table).

### `periodic-table-speed-drill` — Periodic Table Speed Drill (base: elements 1–54)
Timed fluency drill: the sim names an element, the student clicks it on a full periodic
table (group/period numbers shown). A miss requeues that element a few questions later.
Live timer; end screen (time, misses, best streak) is meant to be shown/screenshotted
to the teacher, not persisted.

### `periodic-table-speed-drill-16` — Elements 1–16 only
Same drill, restricted to the first 16 elements.

### `periodic-table-speed-drill-36` — Elements 1–36 only
Same drill, restricted to the first 36 elements.

### `periodic-table-speed-drill-88-no-lanthanoids` — Elements 1–88, no lanthanoids
Same drill, extended range with the lanthanide row excluded.

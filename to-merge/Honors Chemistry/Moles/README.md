# Moles — Simulation Index

**Course:** Honors Chemistry
**Schoology unit:** Moles
**Last updated:** 2026-09-07

Each simulation folder holds `<name>/index.html` + `imsmanifest.xml`, with a ready-to-upload
`<name>-scorm.zip` beside it. All are SCORM 1.2, completion-graded, no student-name gate.

## Simulations

### `mole-conversions-single-element` — Mole Conversions: Grams, Moles & Atoms
Drag-and-drop conversion-factor practice for a single element only — grams ↔ moles
(molar mass) and moles ↔ atoms (Avogadro), each tile with a flip button. The student
types the element's molar mass from the periodic table (2 decimals; H accepts 1.008 or 1.01).
**Completion:** 6 problems — two g→mol, one atoms→mol, one mol→g, one g→atoms, one atoms→g.

### `molar-mass-of-compounds` — Molar Mass of Compounds
A 7-slide beginner lesson (atoms vs. molecules, subscripts, what molar mass means, two
worked examples) followed by calculating the molar mass of 5 simple binary compounds —
the student types each element's atomic mass and the total.
**Completion:** finish the lesson + 5 molar masses correct.

# Reactions — Simulation Index

**Course:** Honors Chemistry
**Schoology unit:** Reactions
**Last updated:** 2026-09-07

Each simulation folder holds `<name>/index.html` (or `<name>.html`) + `imsmanifest.xml`,
with a ready-to-upload `<name>-scorm.zip` beside it. All are SCORM 1.2, completion-graded,
no student-name gate.

## Simulations

### `equation-balancing-practice` — Chemical Equation Balancing Practice
Balance chemical equations by adjusting coefficients. Fixed pool of 10 problems
(3 easy / 3 medium / 4 hard), unlimited retries, no skip.
**Completion:** all 10 balanced.

### `reaction-type-identification` — Reaction Type Identification Practice
Classify a reaction as synthesis, decomposition, single replacement, double replacement,
or combustion. 100-problem bank, no-repeat draw, unlimited retries.
**Completion:** 25 correct.

### `balancing-and-reaction-types` — Potion Lab: Balancing and Reaction Types
Halloween-themed sub-day sim. Part 1: balance 8 equations (type coefficients or use up/down arrows;
unlimited tries; work on paper). Part 2: classify reactions by type from the 100-reaction bank,
2 tries each, 3 correct required for each of the 6 types (18 total). Missing both tries explains
the reaction, doesn't count, and re-queues that type a few reactions later.
**Completion:** all 8 balanced + 18 correct (3 per type). Completion grade only (no score reported).

### `redox-reaction-identification` — Redox Reaction Identification Practice
Decide whether a given reaction is oxidation–reduction, and identify what is oxidized /
reduced (oxidation-state changes).

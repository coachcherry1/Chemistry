## Simulations

### `acetone-iodine-kinetics-v1` — Kinetics of the Iodination of Acetone
A method-of-initial-rates virtual lab.

1. **6-slide briefing** with an embedded concept check on slides 1–3 (catalysts, why the
   colorimeter reads 460 nm, why coefficients ≠ orders); Next is locked until each check
   is answered. A "ready to begin" modal follows.
2. **Run 1** baseline (given), then the student **designs Runs 2–4** to change one reagent
   at a time (the bench blocks two-variable changes). Every run is made up to 20.00 mL.
   A stopwatch times the colour loss; a colorimeter logs A at 460 nm.
3. **Analysis** — read each order off the data, cross-check the I₂ order against three
   integrated-rate-law plots (only A-vs-t is straight), write the rate law, compute *k*
   from four runs and again from the graph slope.
4. **Run 5** — predict the time from your own rate law and *k* before measuring, then verify.

The rate constant *k* is randomized per student, so data differs but the orders
(1 acetone, 1 H⁺, 0 I₂) do not. Progressive disclosure + auto-scroll throughout.
**Completion:** finish all five runs and the analysis → completion grade to Schoology.

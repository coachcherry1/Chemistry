Valence Electrons, Lewis Symbols & Reactivity

Same number of valence electrons → same column → similar reactivity

What you’ll do

For each element you’ll work through three steps, and the next step only opens once the one before it is right:

  1. Choose the number of valence electrons from the element’s place on the periodic table.
  2. Build its Lewis dot symbol — place the dots around the symbol, one on each side before you pair them up.
  3. Pick its reactivity partner — the other element that reacts most like it, because it has the same number of valence electrons.

Completion & grading

  • Work through 10 elements, with every main group represented.
  • Every step has to be correct before you move on.
  • Finish all ten and your grade is submitted to Schoology automatically. It takes about 10–15 minutes; use the Save progress button at the top if you need to stop and pick it up later.

Step 1 — How many valence electrons?

Valence electrons are the outer-shell electrons. For a main-group element you can read the count straight off the group number.

Step 2 — Build the Lewis dot symbol

Click a side of the symbol to add a dot (click again to pair it, once more to clear that side). Put one dot on each of the four sides first, then start pairing.

Step 3 — Which element reacts most like this one?

Elements in the same column have the same number of valence electrons, so they gain, lose, or share electrons in the same way — that is what makes their reactivity similar.

# Bonding — Simulation Index

**Course:** Honors Chemistry
**Schoology unit:** Bonding
**Last updated:** 2026-09-07

Each simulation folder holds `<name>/index.html` (or `<name>.html`) + `imsmanifest.xml`,
with a ready-to-upload `<name>-scorm.zip` beside it. All are SCORM 1.2, completion-graded,
no student-name gate.

## Simulations

### `chemical-bonding-prediction` — Chemical Bonding Type Prediction
Given an element pair or compound, predict the bond type (ionic / covalent / metallic)
from position on the periodic table and electronegativity. Merged simple + advanced bank
(~99 compounds).
**Completion:** 20 correct.

### `Binary-Ionic-Compound-Builder` — Binary Ionic Compound Builder
Given a binary ionic compound name, click its metal then its nonmetal on a full,
unhighlighted periodic table (order enforced), set each ion's charge and atom count in a
modal, then click subscript badges to write the actual formula. Per-problem summary recaps
ion charges, the charge-balance math, and the final formula.
**Completion:** 10 compounds (configurable 1–50).

### `Transition-Metal-Compound-Builder` — Transition Metal Compound Builder
Same click-the-table / two-modal flow for the 4 common variable-charge metals
(iron ±, copper ±, lead ±, manganese ±) named with a Roman numeral. Built to counter the
misconception that every ionic compound needs a Roman numeral — the title screen, the
charge choices offered, and the per-problem summary all reinforce that only these metals do.
**Completion:** 10 compounds (configurable).
